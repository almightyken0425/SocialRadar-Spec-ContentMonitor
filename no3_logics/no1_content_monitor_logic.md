# 巡邏分類推播邏輯: ContentMonitorLogic

## searchKeyword 依關鍵字搜尋

- **輸入:**
  - 監控關鍵字
- **執行:**
  - 對平台送出關鍵字搜尋請求
  - 搜尋結果依最新時間排序，不採預設熱門排序
- **回傳:**
  - 該關鍵字的貼文清單

## extractCandidates 擷取貼文欄位

- **輸入:**
  - 貼文清單
- **執行:**
  - 逐篇擷取作者、內文、讚數、留言數、發文時間、原文連結
- **回傳:**
  - 候選貼文清單

## applyThreshold 套用門檻篩選

- **輸入:**
  - 候選貼文清單
  - 篩選門檻，含新鮮度時數與讚數上限
- **執行:**
  - IF 發文時間超過門檻時數:
    - **回傳:** 捨棄
  - IF 讚數不小於門檻:
    - **回傳:** 捨棄
  - ELSE:
    - **回傳:** 保留，進入內容相關性判斷

## judgeRelevance 判斷內容相關性

- **輸入:**
  - 通過門檻篩選的候選貼文
- **字面命中判斷:**
  - **條件:**
    - 貼文內容與搜尋關鍵字語意脫節，屬平台斷詞誤判
  - **行為:**
    - 命中即捨棄，不進入下一層判斷
  - **理由:**
    - 平台搜尋非整句比對，會拆字命中不相關內容
- **產品類別判斷:**
  - **條件:**
    - 貼文主題與個人記帳、預算追蹤、分帳、理財工具的產品類別不符
  - **行為:**
    - 命中即捨棄
  - **理由:**
    - 排除記帳士代辦、經理職涯討論、保險銷售、投資書單等不同受眾內容
- **內容厚度判斷:**
  - **條件:**
    - 貼文內容過短，不足以構成有意義的推播
  - **行為:**
    - 命中即捨棄
- **情報價值判斷:**
  - **條件:**
    - 貼文不具備競品動態、使用者痛點、產業趨勢任一種參考價值
  - **行為:**
    - 命中即捨棄
  - **理由:**
    - 純字面重疊但無實質意義的內容不計入情報
- **回傳:**
  - 通過四層判斷的貼文清單

## buildDiscordDigest 組裝推播內容

- **輸入:**
  - 通過判斷的貼文清單
- **執行:**
  - 逐篇組裝一筆 embed
  - title 為作者帳號
  - description 為貼文原文，不經摘要或改寫
  - url 為原文連結
  - footer 為讚數、留言數、發文時間
  - IF description 原文字元數超過 4000:
    - 擷取前 4000 字元，結尾加上刪節號
  - ELSE:
    - 原文照登
  - 每 10 筆 embed 分為一批
- **回傳:**
  - 一批以上的推播內容

## pushToDiscord 推播至 Discord

- **輸入:**
  - 推播內容
  - Webhook 位址
- **性質:**
  - 網路請求
- **執行:**
  - 逐批對 Webhook 位址發送 HTTP POST 請求
  - IF 回應非成功狀態:
    - 記錄失敗原因，不重試超過三次
  - ELSE:
    - 記錄本輪關鍵字命中統計
